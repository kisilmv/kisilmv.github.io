# Live Slides — інтерактивні заняття з телефонами студентів

Ви керуєте презентацією з комп'ютера (пульт із нотатками, ключами й відповідями). Студенти бачать слайди на телефонах у вертикальному форматі й відповідають на завдання. Синхронізацію забезпечує Firebase (безкоштовний тариф Spark).

## Що в папці

| Файл | Призначення |
|---|---|
| `presenter.html` | Пульт викладача (відкриваєте на ноутбуці) |
| `live.html` | Сторінка студента (телефон) · з `&view=screen` — екран для проєктора |
| `lessons/<назва>/slides.js` | Публічний зміст уроку (бачать студенти) |
| `lessons/<назва>/teacher.js` | Нотатки й ключі (лише для пульта) |
| `firebase-config.js` | Ключі вашого проєкту Firebase + ваша адреса Google |
| `database.rules.json` | Правила безпеки бази (вставляються в консоль Firebase) |
| `assets/` | Ядро, стилі, генератор QR-кодів |

## Крок 0. Перевірка без Firebase (5 хвилин)

1. Завантажте папку `live-slides` у репозиторій сайту (наприклад, як `/live/`).
2. Відкрийте `https://<ваш-сайт>/live/presenter.html?demo`.
3. В інших вкладках **того самого браузера** відкрийте посилання з QR-вікна (воно вже містить `&demo`). Увімкніть у DevTools вигляд телефона (F12 → значок телефона), щоб побачити вертикальний формат.

Демо-режим працює лише між вкладками одного браузера. Він потрібен, щоб перевірити вигляд і логіку уроку.

## Крок 1. Створити проєкт Firebase

1. Відкрийте <https://console.firebase.google.com> → **Add project** (Google Analytics можна вимкнути).
2. **Build → Realtime Database → Create database**. Розташування: **europe-west1 (Belgium)**. Режим: **Start in locked mode**.

## Крок 2. Увімкнути вхід

**Build → Authentication → Get started → Sign-in method**. Увімкніть два способи:
- **Google** (для вас як викладача);
- **Anonymous** (для студентів: без реєстрації, але кожен телефон отримує власний ідентифікатор, тож проголосувати двічі не вийде).

Потім **Authentication → Settings → Authorized domains → Add domain**: додайте домен сайту (наприклад, `mykola.github.io` або власний домен).

## Крок 3. Правила безпеки

1. Відкрийте `database.rules.json` і **двічі** замініть `ваша.адреса@gmail.com` на свою адресу Google (малими літерами).
2. **Realtime Database → Rules**: вставте весь вміст файлу → **Publish**.

Що гарантують правила:
- змінювати слайди, бачити відповіді й кількість учасників можете **лише ви**;
- студент може записати тільки **власну** відповідь, тільки **на поточний слайд** і тільки **поки приймання відкрите**;
- відповідь — лише рядок до 300 символів.
- відповісти може лише студент, який назвався (прізвище та ім'я); ім'я записується один раз на кімнату, і змінити його студент уже не може;
- імена бачите лише ви.

## Крок 4. Ключі в `firebase-config.js`

**⚙ Project settings → General → Your apps → значок `</>` (Web)** → зареєструйте застосунок (Hosting не потрібен) → скопіюйте об'єкт `firebaseConfig` у `firebase-config.js`. Обов'язково має бути рядок `databaseURL`. Якщо його немає, скопіюйте конфігурацію ще раз уже після створення бази.

Також вкажіть свою адресу в `TEACHER_EMAIL`.

> Ключ `apiKey` не є секретом: це ідентифікатор проєкту, а не пароль. Захист забезпечують правила з кроку 3.

## Проведення заняття

1. Відкрийте `presenter.html?lesson=demo` і увійдіть через Google. Код кімнати генерується автоматично, а на екрані одразу з'являється великий QR.
2. Студенти сканують QR або відкривають `live.html` і вводять код.
3. Якщо ноутбук **дублює** екран на проєктор, студенти бачитимуть ваші нотатки. Краще режим **«Розширити»** (Win + P → Extend): пульт лишається на ноутбуці, а на проєктор перетягніть вікно «Проєктор ↗».

### Клавіші пульта

| Клавіша | Дія |
|---|---|
| → · пробіл · PageDown | наступний крок / слайд (працюють і пульти-«клікери») |
| ← · PageUp | назад |
| **R** | показати / сховати правильну відповідь |
| **S** | показати розподіл відповідей на телефонах (для тестових питань) |
| **L** | закрити / відкрити приймання відповідей |
| **B** або **.** | пауза: телефони показують «Подивіться на викладача» |
| **Q** | великий QR-код |
| **T** | таймер (подвійний клік — скинути) |
| Home / End | перший / останній слайд |

Клавіші працюють і в українській розкладці.

### Нова група — нова кімната

- Кожне відкриття пульта **без** `&room=…` в адресі створює нову кімнату з новим QR. Закладку зберігайте лише без `&room=…`.
- Кнопка **Завершити** (праворуч унизу) закриває кімнату: телефони показують «Заняття завершено», повторно приєднатися неможливо, відповіді стираються. Після цього пульт пропонує почати нове заняття з тим самим уроком.
- Якщо пульт відкрито зі старою адресою (з історії браузера): завершену кімнату чи кімнату іншого уроку він замінює новою автоматично; кімнату, не використовувану понад 3 години, пропонує замінити. Якщо ж ви просто оновили сторінку під час заняття, пульт продовжить з того самого слайда.
- Студентська сторінка не показує заняття, у якому понад 6 годин нічого не відбувалося, і просить сканувати новий QR.

## Як створити новий урок

Скопіюйте `lessons/demo` у `lessons/<нова-назва>` і відредагуйте обидва файли. Урок відкривається за адресою `presenter.html?lesson=<нова-назва>`.

Типи слайдів у `slides.js`:

```js
{ id: 's1', type: 'title',   kicker: '…', title: '…', subtitle: '…' }
{ id: 's2', type: 'content', title: '…', items: ['…', '…'], reveal: true }   // reveal — по одному пункту
{ id: 's3', type: 'vocab',   term: '…', ipa: '/…/', pos: 'noun', def: '…', example: '…', uk: '…' }
{ id: 's4', type: 'mcq',     prompt: '…', options: ['…', '…', '…'] }
{ id: 's5', type: 'gap',     instruction: '…', prompt: 'She ___ (look) forward to it.', placeholder: '…' }
{ id: 's6', type: 'open',    prompt: '…', placeholder: '…' }
{ id: 's6m', type: 'match',  prompt: '…', left: ['…', '…', '…', '…'], right: ['…', '…', '…', '…', '…', '…'] }  // праворуч 1–2 зайві
{ id: 's7', type: 'end',     title: '…', text: '…' }
```

Відповідний запис у `teacher.js` (ключ `id` має збігатися):

```js
s4: { notes: '<p>…</p>', answer: { correct: 2, explain: '…' } },            // номер з 0
s5: { notes: '…', answer: { text: 'is looking', accept: ['is looking', "'s looking"], explain: '…' } },
s6m: { notes: '…', answer: { pairs: [3, 0, 5, 2], explain: '…' } },        // для кожного лівого пункту — номер правого (з 0)
```

**Зіставлення (`match`).** Студент обирає літеру біля кожного пункту й одразу бачить на телефоні свої стрілки; «Надіслати» відправляє всі пари разом. Після R правильні пари з'єднуються зеленими стрілками (і на екрані, і на телефонах), хибні вибори студента позначаються червоним пунктиром, під слайдом — «Правильно: 3 з 4». На пульті ще до R видно бліді стрілки ключа, а в панелі відповідей — відсоток правильних для кожного пункту й рахунок кожного студента. На телефоні вміщається 4–5 пар і 6 коротких варіантів (до 3–4 слів).

У текстах можна використовувати HTML: `<b>`, `<i>`, `<br>`, `<span class="muted">`.

## Важливі обмеження

- **Публічний репозиторій.** Студентська сторінка не завантажує `teacher.js`, і ключ надходить на телефони лише після R. Проте файл у публічному репозиторії технічно доступний за прямою адресою. Для звичайних вправ цього достатньо. Для контрольних із реальними оцінками ключі краще не викладати на GitHub і проводити такі тести окремо.
- **Кількість учасників.** Безкоштовний тариф дозволяє 100 одночасних підключень на проєкт. Цього вистачає для групи чи потоку до ≈95 осіб (одне місце займає пульт, одне — проєктор).
- **Інтернет.** Кожен телефон потребує з'єднання, але трафік мінімальний. Після втрати зв'язку сторінка сама перепідключиться й покаже поточний слайд.
- **Старі кімнати.** Дані кожної кімнати зберігаються в базі й займають кілобайти. Раз на семестр їх можна видалити: Realtime Database → Data → `rooms` → 🗑.


## Імена студентів і модерація відповідей

🔸 Під час входу студент вказує **прізвище та ім'я**. Без цього сервер не прийме від нього жодної відповіді.
🔸 На пульті біля кожної відповіді видно автора. Для тестових питань під кожним варіантом видно, хто його обрав. Унизу панелі є список **«Не відповіли»**, а в панелі **«Учасники»** показано всіх присутніх.
🔸 Відповіді групі **не показуються автоматично**. Біля кожної відкритої відповіді (і кожного варіанта в пропусках) є кнопка **«На екран»**. На проєкторі й телефонах з'являється лише схвалене, і **без імен**. «Прибрати всі» очищає стіну слайда.
🔸 **Звіт ⬇** завантажує таблицю для Excel: рядок на студента, стовпчик на завдання, ✓/✗ там, де є ключ. Під час «Завершити» пульт пропонує завантажити звіт, бо після завершення відповіді стираються.
